포트폴리오

소개

정보보호학을 전공하는 학생으로서, 웹 보안과 네트워크 보안에 관심이 많습니다. Python과 Linux를 활용한 실습 경험이 있으며, Wireshark를 사용하여 패킷 분석을 수행한 바 있습니다. KOICA NGO 활동에도 관심이 있어, 사회적 가치를 창출하는 보안 솔루션 개발에 기여하고자 합니다.

미래 목표

  • 정보보안 전문가로서의 성장
  • 실무 중심의 보안 역량 강화
  • 지속적인 학습과 연구
  • 사회적 가치를 창출하는 보안 솔루션 개발

학습 여정

JAN · 2027

웹 보안 기초(XSS/SQLi) 학습 - 교육 사이트 구현

웹 보안의 핵심 개념인 XSS와 SQL Injection 공격 원리를 학습하고, 이를 시연하는 인터랙티브 교육 사이트를 제작하였습니다. OWASP Top 10 취약점 중 하나인 XSS와 SQLi의 공격 방식과 방어 방법을 이해하는 데 중점을 두었습니다.

네트워크 프로토콜(TCP/IP) - Wireshark 패킷 분석

TCP/IP 프로토콜의 작동 원리를 학습하고, Wireshark를 사용하여 실제 패킷을 분석하였습니다. 네트워크 통신에서 발생할 수 있는 보안 위협을 이해하고, 이를 방지하기 위한 기본적인 기술을 익혔습니다.

리눅스 기초 - 로그 분석 자동화 스크립트

리눅스의 기본 명령어와 쉘 스크립트 작성법을 학습하고, 시스템 로그 파일을 자동으로 분석하는 스크립트를 제작하였습니다. 반복적인 로그 검토 작업을 자동화함으로써 효율적인 시스템 관리 방법을 익혔습니다.
